# Product

## Purpose

This project hosts a personal/professional website built with Hugo.

## Current functionality

- Homepage content from `content/_index.md`
- About page content under `content/about/`
- Services page content under `content/services/`
- Static media assets and profile images served with the site

## User value

- Fast-loading static pages
- Easy content editing via Markdown
- Theme-based visual consistency

## Future extensions

- Add new sections under `content/` for blogs, projects, or portfolio entries
- Customize layouts in `layouts/` to override theme defaults
- Add multilingual content via `i18n/` if needed
